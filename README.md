# ごっくん だいぼうけん 〜おにぎりくんを 胃まで とどけよう〜

▶ **ゲームであそぶ:** https://sakusaku117.github.io/gokkun-adventure/

飲み込み(嚥下)の5つの段階を、おにぎりのキャラクターと一緒にたどるクイズゲームです。クイズに正解すると、おにぎりくんがのどの中を進みます。小学生から大人まで、スマートフォンで遊べます。

`index.html` をブラウザで開くだけで使えます。インストールや通信は不要です。

## ステージ

| ステージ | 段階 | おにぎりくんの動き |
|---|---|---|
| 1 さがす | 先行期 | 目と脳で食べものを見つけて「いただきます!」 |
| 2 くだく | 準備期 | 歯と舌で「モグモグ」、つばと混ざって「つるん!」 |
| 3 すべる | 口腔期 | 舌のベルトコンベアで「シュルッ」とのどへ |
| 4 ゴックン | 咽頭期 | 空気と食べものの交差点。フタが閉じて「ゴックン!」 |
| 5 ゴール | 食道期 | 波に乗って「ゴロゴロ」、胃にとうちゃく |

各ステージ2問、全部で10問の3択クイズです。

## 遊び方

- まちがえると、おにぎりくんが「むせっ!」として、ヒントが出ます。答え直せるので、ゲームオーバーはありません。
- ゴールでは「ごっくんマスター」の認定と、1回で正解した問題の数が星で出ます。
- 効果音は、「おと」のボタンで切り替えます。最初は音なしです。

## プライバシー

名前などの入力欄はありません。どこにも送信・保存されません。アクセス解析や外部サービスの読み込みもありません。

## ご注意

このゲームは、一般の方向けに飲み込みのしくみを紹介するもので、からだの形や動きはわかりやすく簡単にしています。病気の診断をするものではありません。飲み込みについて気になることがあるときは、医師や言語聴覚士にご相談ください。
